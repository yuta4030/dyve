# 作り直し：次に直すところ（案）

使ってみたレポート（作り直し版 e8656b8 を既定のまま立てた回）から、`next/` で次に直すところをまとめた手順書。開発を受け持つ人が、これだけ読んで始められる粒度で書く。絵は `rebuild-next-sketch.html`（ブラウザで開く。番号はこのファイルの節と同じ）。

これは案で、決まりの正本ではない。直したら、決まった形を `REBUILD.md`（仮の決め・未決）と `next/README.md`（設定）に書き、このファイルと絵は消す。

## 0. はじめに

### 困りごとと直すところ

| 困りごと | 原因 | 直すところ |
|---|---|---|
| 「B で」が届かない。言い直しても通らない | 畳むと記号を返し、次のセッションが同じ字をもらう。済みは `#番号` でしか指せない | 1 |
| 届かなかったことに気づけない | 係は黙って `none` にし、画面は薄い字で「どこにも届けていない」だけ | 2 |
| 取り違えて届いた発言を移せない | 届け直しは、届けていない発言にしか効かない | 3 |
| カードとパネルが物足りない | 届け先を速く決めたい口と、カードを書く口が同じモデル | 4 |
| 同上 | カードはパネルを 3 枚まで持つのに、オーバービューは 1 枚目の頭しか出さない。列は 230px、いまどこまでは 2 行 | 5 |
| 同上 | 係は道具を持たず、セッションが文章に書いたことしかパネルにできない | 6 |

### 進め方

- 順番は 1 → 2 → 3（届け先）、4（係のモデル）、5 → 6（カード）。番号ごとにコミットを分け、一つ終わるたびにテストを通す
- テストは `npm run test:next`。外にはつながず、`next/test/fake-claude.js` で回す。画面は `node next/bin/dyve.js serve --claude next/test/fake-claude.js` で立てて目で確かめる
- 守ることは `CLAUDE.md` の「作り直し中」「技術スタック」「文書を直すとき」と、`REBUILD.md` §3 の原則。`src/` は直さない
- 画面の言葉は `ui.html` の `L` に足す。ダイアログ・フォーカスを奪う・音・見ている位置を動かす、はしない（`next/test/ui.test.js` が確かめている）
- 記録の形は足すだけにする。いまの `record.jsonl` は、そのまま当て直せること

### 先に決めてほしいこと

どれも、決まらなければ「案」のまま進められる。

| 決めること | 案 | 代わりに払うもの |
|---|---|---|
| 記号 | セッションごとに固定し、畳んでも返さない | 字が Z を越えて増える（AA・AB…） |
| 付け替えたとき、元のセッションに知らせるか | 知らせない。まだ渡していなければ取り消す | 元のセッションが、取り違えた頼みで動き続けることがある |
| カードを書く口の既定のモデル | `sonnet`（発言を読む口は `haiku` のまま） | カードが出るまで少し遅く、費用が増える |
| カードの大きさ | ステートとパネルの数から導く。人も AI も変えられない | 大きさが変わると、後ろのカードの位置がずれる |
| 利用枠の残りを出す場所 | オーバービューの見出しの行 | — |

## 1. 記号を固定する

**ねらい**：一度「B」と呼んだセッションは、畳まれても戻っても B のまま。済みでも「B で」で戻る。

**決め**
- 記号は、セッションができた順に振る（1 つ目が A）。畳んでも、戻っても変えない
- 係は、出ているものも済みのものも記号で指す。`#番号` はやめる

**触るところ**
- `next/src/state.js`
  - `freeSymbol` を消す。`open.apply` は `sym: symbolOf(s.sessions.length)`
  - `fold.apply` の `x.sym = null` と、`pass.apply` の `x.sym = freeSymbol(s)` を消す
  - `callOf` は `x.sym` を返すだけにする
- `next/src/kakari.js`
  - `SaidMouth._apply` のセッション探し（`(s.folded ? "#"+s.id : s.sym) === key`）を、`s.sym === key` にする。係に見せていない古い済み（`DONE` の 8 件より前）も、記号が合えば届ける
- `next/kakari/発言.md`
  - 「済みのセッション」は記号で渡る、と直す。`session` に書くのはいつも記号
  - 記号で呼ばれたら、済みでも、一覧になくても、その記号を書く
  - 「済みに戻すか新しく起こすか迷ったら、新しく起こす」は、名前や中身で当てるときだけに残す
- `next/src/ui.html`
  - `fromHead`：済みでも記号を出す（薄く）。`.dname` は要らなくなる
  - `Overview.shelf`：済みの行の頭に記号を出す
  - `chipOf` と `L.toDone`：済みへ届いた発言の印を「→ B 名前（済み）」にする

**記録の形**：変わらない（記号は導く）。古い記録を当て直すと、記号はできた順に振り直される。

**テスト**
- 書き直す：`e2e.test.js`（62〜72 行）、`fold.test.js`（75〜102・148 行）、`kakari.test.js`（197 行「記号：空いているいちばん若い字…」）
- 足す：A・B を起こす → 両方畳む → 3 つ目は C。係が `session: "B"` を返すと、済みの B が B のまま戻る

**済んだと言える条件**：レポートの流れ（A・B を畳んだあとに新しいセッションが起き、「B で並行して」と言う）で、発言がもとの B に届く。

## 2. 届けなかったわけを返す

**ねらい**：頼んだつもりの発言が届かなかったら、その発言の下に、わけと言い直し方が一行で出る。独り言は、いまのまま静かに残る。

**決め**
- `none` を二つに分ける。独り言・あいづちは、わけを書かない。頼みや答えらしいのに届け先を決められなかったものは、わけを一行で書く
- わけは、その発言の下に置くだけ。ダイアログにしない。チャットの位置も動かさない
- 言い直せば、いまの届け直し（`resend`）で届く。新しいしくみは足さない

**触るところ**
- `next/src/kakari.js`
  - `SAID_SCHEMA` の項目に `why`（文字列）を足す
  - `_apply`：`to: "none"` で `why` があれば、`aside` に `why`（一行、80 字まで）を付けて置く
  - `_apply` が自分で作る `miss` の文を、人が読む言葉にする（「ありもしないセッション「B」を返した」→「「B」というセッションがない」など）
- `next/kakari/発言.md`：`none` の説明に足す。「頼みや答えらしいのに届け先を決められないときは、`why` に、何がわからなかったかと、どう言えば届くかを一行で書く。独り言には書かない」
- `next/src/state.js`：`aside.make({ said, why = null })`、`apply` で `p.why` に持つ（`pass` で届いたら消す）
- `next/src/ui.html`
  - `chipOf`：`s.why` があれば `L.asideWhy(why)` を、薄くしないで出す。`s.miss` も薄くせず、理由を title ではなく文で出す
  - 色は人のもの（`--you`）。`.chip.warn` を足す

**記録の形**：`aside` に `why` が足される（なくてよい）。

**テスト**（`kakari.test.js`）
- `why` 付きの `none` は、`aside` に `why` が残る。`why` なしはいままでどおり
- わけの付いた発言を、次の発言で名前を言って届け直せる（230 行のテストの形）
- `ui.test.js`：`chipOf` が、わけの付いた発言を薄くしない

## 3. 届けた発言を付け替える

**ねらい**：「A じゃなくて B」で、A に届いた発言が B に届く。

**決め**
- 付け替えるのは、人が声でそう言ったときだけ。係が自分からは付け替えない。画面で付け替える操作は持たない
- 元のセッションにまだ渡していなければ（待たせているだけなら）取り消す。もう渡していたら、元のセッションには何もしない
- 付け替えで頼みが一つもなくなったセッションは、そのまま畳む
- 付け替えた発言では、ほかのセッションを畳まない（届け直しと同じ）

**触るところ**
- `next/src/kakari.js`
  - `saidPrompt` が中で作っている「直前の発言」（`before`）を、`SaidMouth.read` で作って `saidPrompt` と `_apply` の両方に渡す
  - `_apply`：返った `says` に「直前の発言」の id があり、`to` が `session` か `new` で、いまの届け先と違えば、`this.sessions.ask(id, { …, move: true })`。言った発言には、いまと同じ `resend` を置く
- `next/kakari/発言.md`：「届け直す」に足す。届けた発言も、人が「A じゃなくて B」「それは B のほう」と言ったときだけ、同じ書き方で付け替えられる
- `next/src/sessions.js` の `ask`：`p.session != null` のとき、`to.move` があり届け先が違えば通す。`pass` に `from`（元のセッション）を付けて置く
- `next/src/state.js` の `pass.apply`：`r.from` があれば
  - 元のセッションの `pending` から外す。外せたら（まだ渡していなかったら）`asked` からも外す
  - `p.from = r.from`、`p.again = true`（`toFold` が畳まない）
- `next/src/kakari.js` の `Folder`：`from` の付いた `pass` のあと、元のセッションの `asked` が空なら `fold` を置く
- `next/src/ui.html` の `chipOf`：付け替えた発言の印は「→ B 名前（A から付け替え）」

**記録の形**：`pass` に `from` が足される（なくてよい）。

**テスト**（`kakari.test.js`・`sessions.test.js`・`fold.test.js`）
- A に届いた発言を B へ付け替えると、`p.session` は B、B の次のターンで渡る
- A が待たせていただけなら、A には渡らない。A がもう受け取っていたら、A のやりとりには残る
- 言われていない発言は付け替えない。同じ届け先への付け替えは何もしない
- 付け替えでは、ほかのセッションを畳まない

## 4. カードを書く口のモデルを分ける

**ねらい**：届け先は速いまま、カードとパネルの質だけ上げる。

**決め**
- 設定を口ごとに書けるようにする。`kakari.said.model`（発言を読む口）、`kakari.session.model`（セッションを読む口）。書かなければ `kakari.model`、それもなければ既定
- 既定は、発言を読む口が `haiku`、セッションを読む口が `sonnet`

```json
{ "kakari": { "said": { "model": "haiku" }, "session": { "model": "sonnet" } } }
```

**触るところ**
- `next/src/config.js`：`KAKARI` に `said`・`session`（中は `model` だけ）を足す。知らない項目は、いままでどおり断る
- `next/bin/dyve.js`（106 行）：`conv(def, schema)` が口ごとのモデルを選ぶ
- `next/README.md` の「設定」

**気をつけること**：係は 60 秒で返らなければ止めて起こし直す（`kakari.js` の `TIMEOUT`）。本物の `claude` で、長いやりとりのカードが時間内に返るかを一度確かめる。

**テスト**：設定の検査（口ごとの `model` が通る、知らない項目は断る）と、口ごとに違うモデルで起きること。

## 5. カードの大きさと、パネルを全部出す

**ねらい**：オーバービューを見るだけで、帰ったものの結果と、人待ちの問いが読める。覗かなくてよい回を増やす。

絵の左がこの形。

**決め**
- カードの順は、いままでどおり並んだ順で、動かない。変わるのは大きさだけ
- 大きさは導く。人も AI も変えられない。記録にも持たない

| 大きさ | いつ | 出すもの |
|---|---|---|
| 小 | パネルがまだない | いまどこまで（2 行）。動いているあいだは、使った道具の新しい 3 行 |
| 中 | パネルが 1 枚、または人待ち | いまどこまで（3 行）・段取り・問いの全文・パネル 1 枚 |
| 大 | パネルが 2 枚以上 | 中と同じものと、パネルを全部（横に並べる） |

- パネルの数は、いちばん新しいカードのパネルと、作業場（6）を足したもの。動き出しても前のカードは残るので、ターンのたびに縮んで広がることはない
- 並べ方は、折り返す flex にする。小は 2、中は 4 の割合で伸び、大は一行を使う。行はいつも埋まり、順は入れ替わらない（grid の dense は順が入れ替わって見えるので使わない）
- 大きさが変わると後ろのカードがずれる。ポインタがオーバービューの上にあるあいだは大きさを変えず、離れたときに変える（押そうとしていたものを動かさない）

**触るところ**
- `next/src/state.js`：`sizeOf(x)`（`"s"`・`"m"`・`"l"`）と、`toolsOf(x, n)`（いまのターンで使った道具の新しい n 行）を足す。どちらも導くだけ
- `next/src/ui.html`
  - `.cards` を flex に。`.card.s`・`.card.m`・`.card.l`
  - `Overview.render`：`sizeOf` でクラスを付ける。ポインタが上にあるあいだの持ち越しは `ui` に持つ
  - カードの中を、左（いまどこまで・段取り・問い）と右（パネル）に分ける。`x.card.panels[0]` だけでなく全部を出す
  - 中・大のカードでは、行の切り方をゆるめる（`list` は 4 → 6 行、`table` は 3 → 5 行）
  - 小のカードで、動いているあいだ `toolsOf` の 3 行を等幅で出す
  - 狭い幅（860px より下）では、どの大きさも一列
- `next/kakari/セッション.md`：パネルは覗かなくてもオーバービューに全部出る、と一行足す（1 枚目に何を置くかの重みが変わる）

**記録の形**：変わらない。

**テスト**
- `card.test.js`：`sizeOf`（パネルなし → 小、1 枚 → 中、人待ち → 中、2 枚 → 大、動き出しても前の大きさのまま）、`toolsOf`
- `ui.test.js`：いまの決まり（外を読まない・`L` にまとめる・ダイアログを出さない）が通ったまま
- 目で確かめる：偽の `claude` で 5 つ起こし、ステートが変わったときに、見ていたカードが押せる位置に残る

## 7. いまはやらないこと

決まっていないか、本体の外で済むもの。

- **前のカードのパネル**（伝言 6 件目）：カードは状態の中で上書きされる。記録には残っているので、覗いたときに前のカードをたどれるようにはできる。見せ方が未決
- **追従**（伝言 5 件目）：どちらの画面の話かが未決
- **view からセッションへ頼みを送る口**：利用者の view は、いまは描くことと、もとのやりとりを光らせることしかできない。取り消せないことに関わるので、別に決める
- **道具を持つパネル係**：5 と 6 を使ってみてから考える
- **書き溜める役割**：本体には足さない。利用者が `~/.dyve/next/roles/<名前>.md` と `config.json` の `tools` で足す
