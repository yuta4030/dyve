# dyve

入力欄が一つのまま、いくつもの仕事を切り替えずに頼める道具。何を確かめたいかは [PLAN.md](PLAN.md)。

## 入れる

Node 20 以上と、入れてログインした [Claude Code](https://docs.claude.com/en/docs/claude-code/setup)（`claude`）が要る。依存はない。

```sh
npm i -g github:yuta4030/dyve#v0.14.0     # 版はタグで固定する
```

入れずに試すだけなら `npx github:yuta4030/dyve#v0.14.0 serve`。

## 立てる

```sh
dyve serve --room <セッションが働く場所>
```

出てきた URL（既定は http://127.0.0.1:4750/）を開く。

- 入力欄の横のマイクを押して話す。話が途切れたところ（既定は 2 秒）でまとめて置かれ、もう一度押すまで聞きつづける。止めたときは、ためていたものをすぐ置く。ブラウザの音声認識（Chrome など）を使うので、声はブラウザの音声認識のサーバーに送られる
- 「dyve」の横に Claude の利用枠を出す（「5h 21%・週 39%」。マウスを載せると、枠ごとに戻る時刻と残り時間）。8 割を超えると色が変わる。セッションが動くたびに更新される
- 返事の右上のボタンで、マークダウンのままコピーする。コードの塊にもコピーのボタンがある
- `sh`・`bash`・`zsh`・`shell`・`console` のコードの塊は ▶ を押すとそのセッションが起きた場所で動き（確かめずに走る。2 分で止める）、終了コードと出力がその下に出る
- 返事の中の手元のファイルの場所（`src/server.js:42`・`~/notes/memo.md`・`/Users/…/a.txt` など）は押すと開く。途中からの場所は、そのセッションが起きた場所と、そのセッションが触った場所から探す。開くものは歯車の「ファイルを開く」で選ぶ：OS の既定のアプリ（既定）か VS Code（行まで飛ぶ。`code` コマンドが要る）。OS の既定で開くと動いてしまうもの（`.command`・`.sh`・`.app`、実行の権限が付いたものなど）は、開かずにフォルダの中で見せる
- 歯車の「リンク」で、当てはまる言葉を押せるようにする決まりを足す（正規表現と URL。URL の `$0` は当たった言葉全体、`$1`… は括弧の中）。例：`[A-Z]+-\d+` → `https://xxx.atlassian.net/browse/$0`。http・https の URL はそのまま押せる
- 「dyve」の横の歯車で設定を変える：声の送り方（間があいたらまとめて／区切りごとにすぐ）・間の長さ（1・2・3・5 秒）・清書（しない／する）。清書すると、係が届け先を決めるついでに聞き違いや言いよどみを直す（呼び出しは増えない）。直した文をセッションに渡し、元の文はチャットの文にマウスを載せると見える。設定は記録に残る
- 入力欄の上のフォルダのチップが、これから起こすセッションの場所。押すとそのすぐ上に小さな欄が出て、フォルダを書いて Enter で変える（前に使った場所はチップを押すだけ。Esc か、もう一度押すと閉じる）。もう起きているセッションは、続きも元の場所で動く。今と違う場所のセッションは、カードに場所のチップが付く
- 上の帯の消しゴム（リセット）は、チャットを空にして止まっているセッションを一覧から外す（長い会話を続けてトークンを食わないように、新しいセッションで始めるため）。外した会話は時計のボタン（履歴）に並び、「戻る」でその会話に戻れる（今の画面は履歴に入る）。戻れば続きも頼める（長い会話をまた読み込むので、トークンはかかる）
- OS の音声入力も使える（間があくと置かれる）。打ったものは Enter で置かれる（改行は Shift+Enter）
- 係が、どのセッションの続きか・新しく起こすかを決める。「A は〜」「B、〜」のように記号で始めれば、そのセッションにそのまま届く
- カードを押すと、そのセッションのやりとりが見える。覗いているあいだの発言は、係を通さずそのセッションに届く（記号で別のセッションを呼んだときだけ係に任せる）。Esc で一覧に戻る
  - 見出しの帯の右：見たページ・書いたファイル・リンクの決まりに当てはまる言葉（課題の番号など）の札
  - 右：決まったこと（✓）とまだのこと（?）の、話題ごとの木。セッションが dyve の道具 `state` で書く
  - 下：セッションが dyve の道具 `ask` で聞いた質問。一問ずつ出て、選択肢を押して ↑（送る）と、答えが一通にまとまってそのセッションに届く。自分で書いて答えたいときは、ふつうに話せばいい（覗いているセッションに届く）。スクロールしても画面の下に留まる。⌄ で上の一行だけに小さくでき、× で下げる
- 発言の下の ⊗（取り消す）で、まだ答え終えていない発言を取り消す（いま答えているところなら止める）。⇄（送り先を変える）で、ほかのセッションか新しく起こす先へ付け替える。間違って新しく起きたセッションは一覧から消える
- 終わったカードは右上のボタンで畳める。一覧の下に小さな札で並び、押せば覗け、札のボタンで広げる。話しかけてまた動きだしたら広がる
- カードと覗いた画面の ■（止める）で、動いているセッションを止める。続きを話せば、同じ会話でまた動く
- リセットしても記録は消えず、次に話すまでは上の帯の戻る矢印（元に戻す）で戻せる
- 止めて立て直しても記録は残り、続きを頼めば同じ会話で再開する

## セッションに貸す道具

dyve はサーバーに MCP の口を持ち、セッションごとに起動のたび作る鍵付きの宛先を `--mcp-config` で渡す。貸す道具は二つで、どちらも聞かずに使える。

| 道具 | 中身 |
|---|---|
| `ask` | 人に聞く。質問ごとに見出し・背景・選択肢（名前・効き目・おすすめ）。画面の下に留まる |
| `state` | 決まったこと・まだのことを、話題ごとの木で書く。画面の右に出る |

Claude Code に設定してあるほかの MCP（Slack など）は、そのまま使える。

## 書き足す

記録と同じフォルダ（既定は `~/.dyve/`。`--data` を変えたらその隣）に Markdown を置くと、dyve の指示の後ろに足される。形は決めない。

| ファイル | 読む者 | 使いどころ |
|---|---|---|
| `用語.md` | 係・セッションの全員 | 製品名・社内の言葉・略語・よく聞き違える言葉（「Toon：音声入力では『問 2』と聞こえる」など） |
| `係.md` | 係だけ | 届け先の決め方のくせ |
| `セッション.md` | セッションだけ | 仕事の進め方の好み |

係は呼ぶたびに読み直すので、書き換えたら次の発言から効く。セッションは起きるときに読むので、次に起き直したときから効く。

## オプション

| オプション | 中身 |
|---|---|
| `--room DIR` | これから起こすセッションの場所（既定：前に画面で選んだ場所。なければいまの場所）。画面でも変えられる |
| `--model NAME` | セッションのモデル（既定：Claude Code の既定） |
| `--kakari NAME` | 係のモデル（既定：`haiku`） |
| `--slots N` | 同時に答えていられるセッションの数（既定：3）。答えている途中のセッションへの言い直しは、空きを待たずに差し込まれる |
| `--data FILE` | 記録（既定：`~/.dyve/record.jsonl`） |
| `--port N` | 待つポート（既定：4750） |

### セッションの権限

セッションは道具を絞らずに、人に聞かずに進む（`--permission-mode auto`）。ファイルを書く、コマンドを動かす、Claude Code に設定してある MCP（Slack など）を使う、もそのままできる。危ない操作（強制 push や大量の削除など）だけは Claude Code の判定が止める。

- 同じ場所のセッションは同時に動く。同じファイルを二つのセッションに直させると、ぶつかることがある
- 送る・投稿する・push する・消すは、頼まれたときだけやるよう指示してある（`prompts/セッション.md`）

## テスト

```sh
npm test
```

外にはつながない。`test/fake-claude.js` が Claude Code のふりをするので、`node bin/dyve.js serve --claude test/fake-claude.js` で費用をかけずに通しで動かせる。

## リリース

1. `package.json` の `version` を上げる
2. `CHANGELOG.md` に `## [<版>] - <日付>` の節を書く（テストが、いまの版の節があるかを確かめる）
3. PR をマージする。main の版にまだタグがなければ、CI が `v<版>` のタグと GitHub Release を作る
4. README の「入れる」の版を新しいタグに直す
